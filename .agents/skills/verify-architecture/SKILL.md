# Verify Architecture

Whenever you make architectural changes, create new components, or modify the structure of the application, you **must** first read and verify your changes against the `design.md` file located at the root of the workspace.

## Instructions
1. Use the `view_file` tool to read `design.md` in the project root.
2. Ensure your planned changes do not violate the architectural principles and structure outlined in the document.
3. If your changes require an update to the architecture, you must update `design.md` to reflect the new architecture.
